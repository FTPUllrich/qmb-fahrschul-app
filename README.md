## 🎯 Über das Projekt

Dieses Tool wurde speziell für den **QMB- & QMF-Lehrgang (TÜV-Standard)** entwickelt, um das Bestehen der Zertifizierungsprüfung spielerisch, stressfrei und nachhaltig zu sichern. Es verzichtet komplett auf komplizierte Server-Installationen (kein Node.js / Python nötig) und kann direkt mit der Klasse geteilt werden.

> [!TIP]
> **Einfach teilen**: Schicke einfach die Datei `qmb_fahrschul_app.html` an deine Mitschüler. Ein Doppelklick reicht aus, um die App im Browser zu starten!

---

## ⚡ Das Fahrschulapp-Lernprinzip (Spaced Repetition)

Das System nutzt einen intelligenten Stapel-Algorithmus zur optimalen Prüfungsvorbereitung:

```
                  ┌────────────────────────┐
                  │   Aktueller Lernstapel │
                  └───────────┬────────────┘
                              │
                    Beantworte Frage
                              │
             ┌────────────────┴────────────────┐
             ▼                                 ▼
    [ Richtig beantwortet ]           [ Falsch beantwortet ]
             │                                 │
             ▼                                 ▼
   Wandert NACH UNTEN in             Wird 2 Plätze weiter VORNE
   den gemasterten Stapel!           wieder NEU NEUGEMISCHT!
```

- **✅ Richtig**: Die Frage wandert nach unten in den Stapel der beherrschten Fragen.
- **❌ Falsch**: Die Frage wird sofort **2 Plätze weiter vorne** in den verbleibenden Stapel untergemischt, sodass sie zeitnah erneut gelernt wird, bis sie sitzt!

## 🏆 Die TÜV-Prüfungssimulation

In der Prüfungssimulation gelten realistische TÜV-Bedingungen:

- ⏱️ **Zeitfenster**: 10 Minuten
- ❓ **Fragenanzahl**: **10 zufällig ausgewählte Fragen** (1 Minute pro Frage)
- 🎯 **Bestehensgrenze**: **75%** (mindestens 8 von 10 Fragen richtig)
- 📋 **Detaillierte Auswertung**: Zeigt am Ende genau, welche Fragen falsch waren, inkl. ISO-Begründungen.

## 🚀 Schnellstart für Mitschüler

1. Öffne die Datei **`qmb_fahrschul_app.html`** per Doppelklick in deinem Webbrowser.
2. Wähle im Menü ein **Thema** oder lerne den gesamten Stapel.
3. Nutze das **QM-Lexikon**, um Fachbegriffe schnell nachzuschlagen.
4. Absolviere die **TÜV-Prüfungssimulation**, um deinen Wissensstand zu testen!
